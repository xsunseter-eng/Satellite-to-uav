# Update Logs

This folder stores chronological project update logs, milestone notes, dataset acquisitions, experiments, and architectural decisions.

## Naming Convention
`YYYY-MM-DD_log_NNN_<short_topic>.md`

Example: `2026-11-23_log_001_initial_setup.md`

## Standard Log Template
```markdown
# Log NNN: <Title>
- **Date:** YYYY-MM-DD
- **Author / Agent:** <Name>

## Summary
Brief overview of what was done in this update.

## Changes Made
- Item 1
- Item 2

## Findings / Decisions
- Key takeaways, trade-offs, or blockers.

## Next Steps
- [ ] Action item 1
- [ ] Action item 2
```
